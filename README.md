# Black Ledger HQ

Public website for Black Ledger HQ, a private commercial intelligence platform focused on marketplace research, product comparisons, sourcing opportunities and AI-assisted business analysis.

## Website

https://jlouriema-stack.github.io/black-ledger-site/

The site is static HTML and CSS with a local SVG favicon. It has no JavaScript, dependencies, build step, forms, analytics, external fonts or API requests.

## Files

- `index.html`: public overview, capabilities, research approach and intended Etsy API use.
- `styles.css`: responsive black, gold and emerald visual identity.
- `favicon.svg`: local brand mark.
- `.nojekyll`: serves the static files directly on GitHub Pages.

## GitHub Pages

Publish from the `main` branch and the repository root (`/`) in **Settings → Pages → Build and deployment → Deploy from a branch**. No paid service or custom domain is required for this public repository.

For local preview, serve this directory with any static HTTP server, for example `python -m http.server 8080`.

## Public content boundary

This repository is only for the public website. Do not commit private application code, credentials, databases, internal business records or marketplace datasets. The Etsy section describes intended use subject to the application's authorized permissions; it does not assert endorsement or a live API connection. Advertised prices are distinct from confirmed acquisition costs and completed sales.
