01 / OVERVIEW

Commercial research,
with the bigger picture.

Black Ledger HQ is a private commercial intelligence platform focused on marketplace research, product comparisons, sourcing opportunities and AI-assisted business analysis.

It brings these areas into a structured research process, helping people examine the information behind an opportunity before deciding what comes next.

This website is a public introduction to the platform. Access to the platform itself is private.

THE RESEARCH STANDARD

Evidence first.
Human judgment
always.

↗
01 / SOURCE

Start with permitted information.

Use authorized sources and keep their context in view, including where information comes from and when it was observed.

02 / COMPARE

Pay attention to the differences.

Product identity, condition, pack size, currency and shipping can change the meaning of an apparent price difference.

03 / REVIEW

Keep assumptions visible.

Advertised prices are distinct from confirmed acquisition costs and completed sales. A research finding is a starting point for verification.

03 / INTENDED API USE

ETSY OPEN API

Marketplace insight.
Responsible access.

Black Ledger HQ intends to use the Etsy Open API to retrieve permitted listing information for product research, advertised-price analysis and marketplace comparisons.

Where available and authorized, this may include listing titles, listing IDs, prices, currencies, shop details and source URLs. Access, retention and any AI-assisted use must remain within the application's granted permissions and applicable Etsy requirements.

◇

This public website makes no Etsy API requests and contains no API credentials or marketplace datasets. Etsy references describe the intended data source and do not imply endorsement.
